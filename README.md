# Use Yolov11 to detect marine debris
Use the TrashCan dataset, derived from the larger J-EDI dataset curated by JAMSTEC. It includes 7,212 images with instance segmentation masks.

Model Selection: YOLOv11s
This project uses YOLOv11s for real-time object detection in PyBullet robot simulation.

Why YOLOv11s?

✅ Optimal Balance: Best trade-off between accuracy and speed
✅ Simulation-Friendly: Perfect for PyBullet real-time environments
✅ Resource Efficient: Reasonable memory and compute overhead
✅ Real-time Performance: Maintains stable simulation frame rates
